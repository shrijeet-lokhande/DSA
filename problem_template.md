# Problem-solving template

Use one copy per problem so each submission remains independent.

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    // Read input, solve the problem, and print the required output.
    return 0;
}
```

For portable code outside GCC, replace `<bits/stdc++.h>` with the specific standard headers you use.
